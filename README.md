# registro de gastos personales
## Aplicación de consola en C# para la gestión y control de gastos personales. Implementa un menú interactivo mediante do-while para registrar, listar y buscar gastos dinámicamente usando listas paralelas.

## Funcionalidades

## Agregar gasto: Registra una descripción y un monto validando entradas (monto mayor a 0 y descripción no vacía).

# Listar gastos: Muestra el listado numerado de gastos registrados junto con la suma total acumulada.

# Buscar gasto: Busca coincidencias de texto dentro de las descripciones sin importar mayúsculas o minúsculas.

 # Salir: Finalización controlada del programa.

 # Abre el archivo RegistroGastos.sln (o el archivo de solución correspondiente) en Visual Studio Community.

  # Presiona F5 para ejecutar con depuración (o Ctrl + F5 para ejecutar sin depuración / dotnet run).
